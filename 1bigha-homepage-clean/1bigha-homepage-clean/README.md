# 1Bigha Clean Homepage

This package contains a clean, responsive homepage refresh for 1Bigha using the approved 1Bigha logo.

## Main changes
- Clean white/green visual system
- Large location-first search
- Property type cards
- Featured property cards
- Trust strip
- Why 1Bigha section
- Seller CTA
- Responsive mobile layout
- Updated header/footer with the approved logo

## Files to replace in your GitHub project
- `app/page.tsx`
- `app/globals.css`
- `app/layout.tsx`
- `public/1bigha-logo.png`

Keep your existing `lib`, `components`, and other route files unless you intentionally want to replace them.
